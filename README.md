# 🛡️ SentinelX  

SentinelX is a **DeFi Risk & Sentiment Intelligence Layer** built on **BlockDAG**.  
It aggregates **on-chain risk metrics**, **social sentiment signals**, and **community-driven submissions** into a single, transparent platform.  

👉 Helping investors, DAOs, and protocols make **safer, data-driven decisions** in DeFi.  

---

## 🚀 Features  

✅ **Protocol Risk Scores** – token + protocol-specific (Aave, Uniswap, etc.)  
✅ **Sentiment Engine** – detects FUD, hype, and market mood from crypto chatter  
✅ **Community-Driven Reports** – analysts, DAOs, and researchers submit reports  
✅ **BlockDAG Oracle Layer** – all submissions stored immutably on BlockDAG  
✅ **Wallet Integration** – instantly check risks before investing

## 🏗️ Tech Stack  

- **Frontend:** React.js + TypeScript + TailwindCSS  
- **Backend:** Express + TypeScript  
- **Blockchain:** Solidity smart contracts on BlockDAG Virtual Machine (EVM-compatible)  
- **Wallets:** MetaMask 
- **Data Layer:** Mocked DeFi data + integration-ready APIs
